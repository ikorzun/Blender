## Как управлять с телефона

- **Смотреть игру** — по ссылке выше, сразу.
- **Читать состояние** — эта страница и журнал прямо на GitHub.
- **Ставить задачи** — через веб claude.ai/code в браузере телефона.
  ⚠️ Сессия с телефона работает **не с маком, а с клоном из GitHub**. Поэтому
  правило одно: всё, что сделано, должно быть запушено. Незакоммиченная работа
  на маке для телефона не существует, и параллельная правка одного файла из
  двух мест даст расхождение — у нас это уже случалось с ветками направлений.
- ⚠️ **Собранный зип для тестеров с телефона не скачать** — он намеренно не
  хранится в репозитории (6.4 МБ на каждый релиз раздули бы его). Чтобы
  качался — нужен GitHub Release; тег `v1-test-158` уже стоит, приложить файл
  можно с твоей стороны одним действием.
