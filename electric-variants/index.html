Electricity around the bonus object

Six looks for the charge slot. The object, its colormap atlas and its matcap are the game's own — the same files the build uses — and the sky behind each tile is the real SKY_STOPS.day palette at the height the slot actually sits. Left cell is enlarged so the detail is visible; right cell is the true 116 px of #chargeBtn.

Object Sky

Picked: variant 6, in the cold palette — it is in the game on the charge slot. Variant 1 stayed as its fallback rather than being removed: when the slot has no live 3D canvas it shows a flat picture, and a shader shell cannot ride on that — the ring can, so the two never show at once.

This page is kept as a reference for the next time a bonus object needs a look. It renders the game's own model, colormap atlas and pack matcap, so anything judged here is judged against the real thing. It is a local bench: open it from the project's own preview server, or use the published copy built by tools/variants-artifact.py.
